使用與備份

開始：匯入 DOCX、文字版 PDF、TXT，或直接貼上劇本。會依本機規則產生可編輯分鏡，目前未接 AI。舊 DOC 請先轉 DOCX；Pages 如沒有內嵌 PDF 預覽，請先在 Pages 匯出 DOCX／PDF。

保存：文字、照片和 Shot Order 自動保存在目前瀏覽器。清除網站資料、無痕模式或更換瀏覽器，都可能無法取回。Cmd／Ctrl + S 可保存完整可編輯 HTML。

手機／iPad：把「工程備份 · JSON」或 Save HTML 放到 iCloud Drive，在另一台裝置開本工具，再用「載入工程」選擇該檔案。照片會一起帶過去；同時修改兩份不會自動合併。

打印：Print / PDF 使用 A4 橫向。請在打印預覽核對頁數、採用 100% 比例，並關閉瀏覽器的頁首／頁尾。

資料：劇本及照片在你的裝置處理，不會上傳至 GitHub。部分格式首次匯入需要連線載入解析套件。
